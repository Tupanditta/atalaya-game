# OBJETIVO
Esta carpeta contiene la especificación de la interfaz y las imágenes que muestran la interfaz deseada a implementar.

- `interfaz.md`: especificación visual (estilo, colores, tipografía, componentes y disposición de cada pantalla). Si una imagen y `interfaz.md` no coinciden, prevalece `interfaz.md`.
- `*.svg`: maquetas de las pantallas a 1920 × 1080.

Las imágenes sirven como base. El trabajo del agente de IA es especificar la interfaz en `interfaz.md` de manera que se parezca lo más posible a las imágenes de esta carpeta.
